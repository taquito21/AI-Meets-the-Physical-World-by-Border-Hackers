# Venue photo capture checklist (per chair and per table)

Shoot in landscape, with even light and no flash glare. Keep the whole object in frame for overall views.
Put a known-size reference (A4 sheet or a tape measure) in at least one overall shot to estimate proportions.

- [ ] Front view (straight on, at mid-height)
- [ ] Rear view
- [ ] Left side
- [ ] Right side
- [ ] Three-quarter view (front-left, slightly above)
- [ ] Top view (chair seat or tabletop surface)
- [ ] Underside, only if safely accessible (turn the chair over; for tables, crouch rather than lift)
- [ ] Close-ups of every visible joint (leg–seat, backrest–upright, leg–apron corner)
- [ ] Close-ups of visible fasteners (screws, bolts, brackets), one per type
- [ ] Floor glides or feet
- [ ] Any existing damage or wear (useful for a genuine demo finding)
- [ ] Manufacturer label or sticker, if present (photograph only; do not invent data from it)
- [ ] Measurements if a tape measure is available: overall height, width, depth, seat height

Save to `engineering-packages/<package>/reference-images/` with names like `front.jpg`, `joint-backrest-left.jpg`.
Photos do not reveal hidden geometry, internal joints, materials or fastener specifications. Record those as assumptions.
